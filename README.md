# Google Advanced Data Analytics

This repository contains materials and labs for the Google Advanced Data Analytics That I learned. It is organized to support learning and hands-on practice with Python, data analysis, and related concepts.

## Structure

- **Labs/**
  - Contains practical Jupyter notebooks for each course.
  - `Course_1/`
  - `Course_2/`
  - `Course_3/`

- **Lecture Notes/**
  - PDF notes for each module and topic.
  - `1 - Foundations of Data Science/`
    - Get started with the certificate program
    - Careers in data science
    - Data driven careers
    - Data careers skill
    - Work in the field
    - Trajectory of the Field
    - Data Professional Career Resources
    - The data project workflow
    - Elements of communication
  - `2 - Get started with python/`
    - Get started with the course
    - Use Python syntax
    - Functions
    - Conditional statements
    - Lists and tuples
    - Dictionaries and Sets
    - Arrays and vectors with Numpy
    - Dataframes with pandas
  - `3- Go Beyond the Numbers Translate Data into Insights/`
    - Get started with the course
    - Use PACE to inform EDA and data visualizations
    - Create structure from raw data
    - The challenge of missing or duplicate data
    - The ins and outs of data outliers
    - Present a story
    - Advanced

## How to Use

1. Review the lecture notes for theoretical understanding.
2. Open the corresponding Jupyter notebooks in the `Labs/` folder to follow along and practice.
3. Use the annotated guides for step-by-step instructions and explanations.

## Requirements

- Python (recommended: Anaconda or Miniconda)
- Jupyter Notebook or JupyterLab
- Common data analysis libraries: pandas, numpy, matplotlib (see individual notebooks for details)

## Purpose

This repository is designed to help learners:
- Build foundational and advanced data analytics skills using Python.
- Practice exploratory data analysis (EDA), data cleaning, and visualization.
- Apply concepts from lecture notes in hands-on labs.
